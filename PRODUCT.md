## Platform

## Stack

Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide React, Server-Sent Events (SSE) streaming, Canvas Confetti.

## Users

Engineering leads, technical founders, and full-stack software architects evaluating AI code generation systems for Stunning.so, looking for production-grade full-stack architecture, prompt engineering depth, and live interactive prototypes.

## Product Purpose

Stunning AI Vibe Coder is an AI-powered full-stack application synthesis studio. It allows developers to describe complex software systems, select dummy external integrations (Stripe, Shopify, Gmail, Slack, Google Sheets, Supabase), and dynamically inject structured schemas, SDK patterns, API route contracts, and security hardening rules into AI system prompts. It generates interactive prototypes, architecture pipelines, runnable TypeScript code, and prompt telemetry with sub-second streaming.

## Positioning

Unlike generic chatbots that output ungrounded code snippets, Stunning Vibe Coder combines dynamic multi-integration prompt injection with an instant 4-tier interactive studio (Live Prototype Sandbox, Visual Architecture Pipeline, Production Code Explorer, and Raw Prompt Inspector) with zero mandatory configuration.

## Operating Context

Modern web desktop and tablet workstations, technical candidate assessment evaluations, architecture synthesis sessions, rapid client prototyping.

## Capabilities and Constraints

- Dynamic context compiler for 6 core SaaS integrations (Stripe, Shopify, Gmail, Slack, Google Sheets, Supabase).
- Low-latency SSE streaming generation endpoint with Gemini/OpenAI API key support.
- Zero-config high-fidelity offline simulation fallback.
- Multi-dimensional response explorer with live stateful sandbox triggers.
- In-app interactive documentation viewers for DECISIONS.md and TECH.md.
- Next.js 15 App Router compatibility with strict TypeScript typing.
